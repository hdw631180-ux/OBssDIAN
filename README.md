# archweb

OS dans le navigateur (Arch tiling + bureau Lumen), avec Synapse intégré et effets sonores.

- `index.html` : l'OS (Synapse est déjà dedans, rien d'autre n'est requis).
- `synapse.html` : Synapse tout seul.

Mise en ligne : tout à la racine du dépôt, puis Settings -> Pages -> branche `main`, dossier `/ (root)`.
Son : bouton ♪ en haut, commande `sound on|off`, ou Réglages.
